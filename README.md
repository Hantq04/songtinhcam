# Steam Calculator (SteamDB Style) 🎮

Ứng dụng Flutter mô phỏng công cụ **Steam Calculator** lấy cảm hứng từ giao diện trực quan và hiện đại của [SteamDB Calculator](https://steamdb.info/calculator/).

---

## 🚀 Hướng dẫn cài đặt và khởi chạy

### 1. Yêu cầu môi trường
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (Khuyên dùng v3.13+ hoặc mới hơn)
- Dart SDK đi kèm Flutter

### 2. Cài đặt dependencies
Chạy lệnh sau tại thư mục gốc của dự án:
```bash
flutter pub get
```

### 3. Khởi chạy ứng dụng

- **Chạy trên Windows Desktop**:
  ```bash
  flutter run -d windows
  ```

- **Chạy trên trình duyệt Web (Chrome/Edge)**:
  ```bash
  flutter run -d chrome
  ```

- **Chạy trên thiết bị mặc định**:
  ```bash
  flutter run
  ```

### 4. Kiểm thử và phân tích mã nguồn
- Chạy toàn bộ tests:
  ```bash
  flutter test
  ```
- Kiểm tra cú pháp và linter:
  ```bash
  flutter analyze
  ```

---

- Lấy Steam Web API Key tại: [Steam Community Developer](https://steamcommunity.com/dev/apikey)
